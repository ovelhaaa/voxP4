  Session            13,480 B  (parser + 8 KiB TX ring + 256 B SEQ guard +

The engine-side applied-target trace (s_last_applied[128] + validity = ~648 B)
is present in BOTH builds, which is why the OFF baseline also grew slightly
versus the original v1 report.

The .data increase is the initialized static control objects. No DSP object
size changed.
