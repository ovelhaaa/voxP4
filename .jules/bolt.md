## 2024-05-24 - Base-2 Math in Compressor Hot Path
**Learning:** Optimizing the compressor hot path by replacing base-10 operations (`std::pow(10.0f, ...)` and `std::log10`) with base-2 equivalents (`std::exp2` and `std::log2`) yields a measurable performance improvement on host x86 benchmarks and aligns with ESP32-P4 performance guidelines. Exact equivalence tests for `delay` and `GainNorm` components need to remain strictly bit-identical, but `compressor` tests require a floating-point tolerance (1e-4f) due to the base-2 approximation.
**Action:** Always prefer `std::exp2` and `std::log2` with precomputed constant multipliers over base-10 functions in DSP hot loops. Update exact-equivalence unit tests to use `std::abs(a - b) < tolerance` for components employing this optimization.
